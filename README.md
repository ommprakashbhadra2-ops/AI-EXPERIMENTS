📌 About the Project

Welcome to my Artificial Intelligence Lab Experiments repository!

This repository contains practical implementations of fundamental Artificial Intelligence algorithms and problem-solving techniques developed as part of my B.Tech in Computer Science and Engineering (AI & ML).

The main objective of this project is to understand how intelligent systems solve problems, explore search spaces, make decisions, and find solutions using different AI approaches.

Through these experiments, I aim to strengthen my understanding of AI concepts by implementing algorithms using Python.

🎯 Project Objectives

- Understand the fundamental concepts of Artificial Intelligence.
- Implement uninformed and informed search algorithms.
- Explore heuristic-based search and optimization techniques.
- Understand adversarial search and game-playing strategies.
- Solve constraint satisfaction and state-space problems.
- Improve logical thinking and problem-solving skills through practical implementation.

🧪 Experiments Included

No.| Experiment| Description
01| Breadth First Search (BFS)| Explores nodes level by level to find a solution.
02| Depth First Search (DFS)| Explores a path deeply before backtracking.
03| Hill Climbing| Uses heuristic evaluation to find an improved solution.
04| A* Search Algorithm| Uses path cost and heuristic estimation to find a path.
05| Minimax Algorithm| Determines the best possible move in a two-player game.
06| Alpha-Beta Pruning| Reduces unnecessary search branches in Minimax.
07| 8-Queens Problem| Places eight queens on a chessboard without attacking each other.
08| Water Jug Problem| Solves a state-space problem using water jug operations.
09| Tic-Tac-Toe| Explores AI-based decision-making in a game.
10| Travelling Salesman Problem (TSP)| Explores finding a minimum-cost route between cities.

⚙️ Installation and Execution

Follow these steps to run the experiments on your local machine.

1. Clone the Repository

git clone https://github.com/ommprakashbhadra2-ops/AI-EXPERIMENTS.git

2. Navigate to the Project Directory

cd AI-EXPERIMENTS

3. Check Python Installation

python --version

Make sure Python is installed on your system.

4. Run an Experiment

For example:

python BFS.py

You can execute other Python files similarly. For filenames containing spaces, keep the filename inside quotation marks.

Note: Some experiments may require supporting Python files from the same repository. Run them from the project directory and check their imports before executing them individually.
