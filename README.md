🤖 Artificial Intelligence Lab Experiments

Exploring the Fundamentals of Artificial Intelligence Through Practical Implementation

Welcome to my Artificial Intelligence Lab Repository!

This repository contains a collection of practical implementations of fundamental Artificial Intelligence algorithms and problem-solving techniques developed as part of my B.Tech Computer Science and Engineering (AI & ML) coursework.

The primary objective of these experiments is to understand how intelligent systems solve problems, make decisions, explore search spaces, and optimize solutions using different AI techniques.

---

🎯 Objectives

- Understand the fundamental concepts of Artificial Intelligence.
- Implement different uninformed and informed search algorithms.
- Explore heuristic-based problem-solving techniques.
- Understand adversarial search and game-playing strategies.
- Develop logical thinking and algorithmic problem-solving skills.
- Gain practical experience by implementing AI algorithms.

---

🧪 List of Experiments

No.| Experiment Name| Description
01| Breadth First Search (BFS)| Explores a graph level by level to find a solution.
02| Depth First Search (DFS)| Explores a graph by going as deep as possible before backtracking.
03| Hill Climbing| Uses a heuristic approach to find an improved solution.
04| A* Algorithm| Finds an optimal path using actual cost and heuristic estimation.
05| Min-Max Algorithm| Determines the best possible move in a two-player game.
06| Alpha-Beta Pruning| Optimizes Min-Max by eliminating unnecessary search branches.
07| 8-Queens Problem| Places eight queens on a chessboard without attacking each other.
08| Water Jug Problem| Solves a state-space problem using water jug operations.
09| Tic-Tac-Toe Game| Implements an AI-based strategy for playing Tic-Tac-Toe.
10| Travelling Salesman Problem (TSP)| Finds a minimum-cost route visiting all given cities.
